# RosellaView

Receive AirPlay screen mirroring from iPhone, iPad and Mac on Fire TV devices running Vega OS, with sound and in full-range colour. Built on [UxPlay](https://github.com/FDH2/UxPlay)'s protocol library.

- [Privacy policy](https://regulad.github.io/RosellaView/)
- [Compatibility](docs/COMPATIBILITY.md)
- Building and repository conventions: [AGENTS.md](AGENTS.md)
- Things learned about developing for Vega: [Vega OS: what we've learned](https://gist.github.com/regulad/d06a96cfe3de8dcf0b13f5df629b9e0b)
